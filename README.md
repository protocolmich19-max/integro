# Запуск браузерной игры «Дурак» — пошаговая инструкция

Это руководство объясняет, как полностью развернуть и запустить онлайн-версию подкидного «Дурака» на 36 карт с виртуальными кредитами. Инструкция рассчитана на новичков и написана простым языком.

## 1. Подготовка компьютера

1. **Установите Node.js версии 18 или новее.**
   - **Windows и macOS:** перейдите на [nodejs.org](https://nodejs.org/), нажмите кнопку **LTS**, скачайте установщик и запустите его, не меняя стандартные параметры.
   - **Linux:** откройте терминал и выполните команду `sudo apt install nodejs npm` (для Ubuntu/Debian) или аналогичную для вашего дистрибутива.
2. **Проверьте, что Node.js установлен.** Откройте новый терминал/командную строку и введите:
   ```bash
   node --version
   npm --version
   ```
   Обе команды должны показать номера версий без ошибок.

## 2. Загрузка проекта

1. Откройте страницу проекта на GitHub.
2. Нажмите зелёную кнопку **Code** и выберите **Download ZIP**.
3. Сохраните архив и распакуйте его в удобную папку, например `C:\Games\durak` на Windows или `~/durak` на macOS/Linux.

## 3. Открываем папку проекта в терминале

1. **Windows:** откройте проводник, перейдите в распакованную папку, кликните правой кнопкой мыши по свободному месту и выберите **Открыть в Терминале** (Open in Terminal). Если такой пункт отсутствует, можно запустить «Командную строку» и перейти командой `cd C:\Games\durak`.
2. **macOS/Linux:** запустите приложение «Terminal» и выполните `cd ~/durak` (подставьте вашу фактическую папку).

## 4. Установка зависимостей

Находясь в терминале внутри папки проекта, выполните команду:
```bash
npm install
```
> **Совет:** набирайте только саму команду `npm install` — без чисел вроде `32` и без служебной строки вида «три обратные кавычки + bash». Если вы копируете команду с сайта, вставьте её в блокнот и убедитесь, что остался только текст `npm install`, а затем вставляйте в терминал.
Команда скачает все необходимые библиотеки и создаст папку `node_modules`. Дождитесь завершения процесса.

## 5. Запуск сервера игры

1. Убедитесь, что вы всё ещё находитесь в папке проекта.
2. Запустите сервер командой:
   ```bash
   npm start
   ```
3. В терминале появится сообщение `Server is running on http://localhost:3000`. Это значит, что сервер успешно запущен. Пока вы играете, **не закрывайте** окно терминала.

## 6. Открытие игры в браузере

1. Запустите любимый браузер (Chrome, Edge, Firefox и т.д.).
2. В адресной строке введите `http://localhost:3000` и нажмите Enter.
3. Загрузится страница игры с лобби. Здесь вы можете создать комнату или присоединиться к существующей.

## 7. Как играть вместе с другом

- **На одном компьютере:** откройте новое приватное/инкогнито окно браузера и снова зайдите на `http://localhost:3000`. Введите тот же код комнаты, что и первый игрок.
- **По локальной сети (Wi‑Fi/кабель):** оставьте сервер работающим. Узнайте локальный IP‑адрес компьютера (например, `192.168.0.10`). Другой игрок на том же Wi‑Fi вводит в браузере `http://192.168.0.10:3000`.

## 8. Остановка сервера

Когда закончите игру, вернитесь в окно терминала и нажмите `Ctrl + C`. Сервер остановится, и можно закрыть терминал.

## 9. Если что-то пошло не так

- **Сообщение `npm: command not found`** — Node.js не установлен или не добавлен в PATH. Повторите установку с [nodejs.org](https://nodejs.org/).
- **Порт 3000 занят** — другая программа использует этот порт. Запустите сервер так: `PORT=4000 npm start`, а в браузере откройте `http://localhost:4000`.
- **Страница не открывается** — убедитесь, что в терминале всё ещё видно сообщение о запущенном сервере, и что вы правильно набрали адрес. Попробуйте обновить страницу (`Ctrl + R` или `F5`).
- **Нет связи между устройствами в сети** — проверьте, что оба устройства подключены к одной сети и что брандмауэр не блокирует соединение.

## 10. Что делать дальше

- Оставьте терминал открытым, чтобы сервер продолжал работать.
- Создайте комнату, пригласите друзей и наслаждайтесь игрой на виртуальные кредиты!

Если возникнут дополнительные вопросы, повторите шаги или обратитесь к сообществу Node.js за помощью.
